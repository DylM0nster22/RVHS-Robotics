The build

The robot
in Room 408.

We're in the second year of the club. The current robot is a 3D-printed combat bot with a drum, four wheels, and a lot of test fits. Here's what's done and what's still changing.

Current build

Printed, wired,
and still changing.

The robot is built around a 3D-printed chassis with a black drum, four blue wheels, and removable white armor. It fits in your hands, which makes it easy to carry to the test table and easy to take apart when something breaks.

How it gets built

Design, print,
wire, test.

Most of the work happens in small loops. A part gets modeled, printed, checked, and changed again.

Start in CAD

Model the part, print a prototype, and check the fit before committing to a final version.

Wire it

Solder the electronics, route the wiring, and test one system at a time.

Drive it

Practice, find the weak point, print a new part, and go again.

Shop rules

Safety glasses on. Training before tools. No powered tests without a check. The robot can wait; nobody gets hurt.
