# Sponsor logos

Drop a sponsor's logo here, then point to it from `assets/data/donors.json`:

```json
{
  "sponsors": {
    "Acme Machine": {
      "logo": "assets/img/sponsors/acme-machine.png"
    }
  }
}
```

- Name the file after the donor as it appears on the Hack Club Bank ledger, lowercase and hyphenated.
- PNG, WebP, SVG, and JPG all work. A square or wide logo with a transparent background looks best; the card shows it at 42px on a white tile.
- Keep files small (under 100 KB). A logo replaces the donor's initials on the wall.
- Ask the sponsor for permission before publishing a logo, and check with the school before adding business marks.

Donors without a logo show their initials instead, so no file is required for a gift to appear.
