3 lb / Vertical spinner

The redemption build. A 5.2-inch vertical spinner on a printed glass-filled nylon hub, belt-driven 2:1 from a 2812 outrunner. Two Repeat 2006 Pro motors drive the wheels directly and two 6S packs run in parallel. Forks for verticals, a wedge for horizontals.

How it works

Real CAD,
no plugin.

The site is still plain HTML, CSS, and JavaScript. The heavy lifting happens ahead of time, and the browser only downloads the model you pick.

Straight from GitHub

Every model links back to its public repository and the original STEP file. Nothing is re-modeled for the site.

Tessellated once

STEP files are converted to compressed GLB assets with OpenCascade and meshoptimizer. The first model loads immediately; the rest wait until you pick one.

Built to explore

Orbit, pan, zoom, wireframe, floor grid, and fullscreen. Keyboard controls work when the viewer has focus.

Viewer controls

Mouse: drag to orbit, scroll to zoom, right-drag to pan. Touch: one finger orbits, two fingers zoom and pan. Keyboard: arrow keys orbit, + and − zoom, R resets, A toggles spin, W wireframe, G grid, and F fullscreen. Buttons: the toolbar does the same thing and works without a mouse wheel.

How accurate is the 3D model?

The geometry comes from each repo's STEP file. Curved surfaces are tessellated into triangles for display, so small curves are slightly simplified, and the mesh is not a substitute for the original CAD. Dimensions listed in the viewer are the model's overall extents in millimeters. Each model is framed to fit the viewer, so scale between different robots is not directly comparable. Print and machine from the STEP file.

Why are some builds missing?

This page focuses on the public combat robots. Workshop projects and other CAD files are left out, and a repo without a STEP file or one that is not public yet does not appear. The library uses the main assembly from each repo, not every individual part STL or print plate. If a build gets a new file, add it to tools/models.json and rebuild the assets.

Credits and reuse

CAD by DylM0nster22 and the listed collaborators. Models are linked from their public repositories; check each repository for license terms before reusing geometry, images, or design files. The 3D viewer uses Three.js (MIT) and the meshoptimizer decoder (MIT), both self-hosted.
