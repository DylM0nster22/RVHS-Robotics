Accessibility

Built for everyone.

We want every student, family member, and community member to be able to use this site and take part in the team.

Questions?

Email rvrobotics@ycusd.org or call the RVHS front office at (530) 822-2500.

Our commitment

Clear, usable,
and welcoming.

This site aims to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. That means readable contrast, keyboard-friendly navigation, meaningful link text, captions and alt text for images, and layouts that work on phones and with screen readers.

Accessibility is an ongoing process, not a one-time checklist. If something doesn't work for you, we want to know.

Keyboard
All navigation, forms, the photo viewer, and the match player can be used without a mouse.
Motion
Animations are reduced or turned off when your device requests reduced motion.
Contrast
Text and controls are designed for strong contrast in the default theme.
Images
Decorative images are hidden from assistive tech; meaningful images have descriptions.
Video
Match videos never autoplay. They open in a player with native controls, and YouTube picks load only after you choose one. If you need a more detailed description of a match, email us.
3D models
The CAD viewer works with a mouse, touch, or keyboard. Each model also links to its original STEP file and GitHub repository, and the model details are available as plain text.
Forms
Every field has a visible label and a clear error path.
